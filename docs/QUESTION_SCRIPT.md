## Confirmation (not a printed field)

Tamil: இந்த விவரங்கள் சரியா? / *Indha vivarangal sariya?*  
English: Are these details correct?  
Help: ஆம் அல்லது இல்லை என்று சொல்லுங்கள்.  
Read-back: நீங்கள் {value} என்று சொன்னீர்கள்.
